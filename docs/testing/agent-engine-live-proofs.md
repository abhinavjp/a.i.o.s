# Agent engine live proofs

The local adapter contract is covered with fakes. Production readiness remains `UNMEASURED` until each engine has an explicit opt-in proof run. Proofs must record executable version, authenticated billing route, isolated configuration/session roots, resumable native identity, attributable structured events, cancellation of the verified process tree, and Sarathi permission enforcement.

Run proofs one engine at a time against a disposable agent/configuration and working root. Never persist credential values; record only the environment-variable name. Do not use bypass-permission flags. An absent, unauthenticated, malformed, or ambiguous result is `unavailable`/`UNMEASURED`, never success.

Hermes currently requires repair of the local UV/Python launcher before any proof. Codex and Claude Code require fresh authenticated probes. No proof in this document claims production readiness.
